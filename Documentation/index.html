Habitline - Habit Tracker Next.js Template

Thank you for your purchase! Habitline is a premium, developer-friendly Next.js template integrated with Tailwind CSS 4, built to help you launch fast and performant habit tracking, productivity, and SaaS websites.

Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS 4 Ready

Introduction

Habitline Next.js Edition is built with clean component architecture and modern React design patterns. This template is extremely fast, highly optimized for search engines (SEO), and provides fully customizable components.

With Next.js App Router structure, page loads are near-instant, and page transitions are seamless. Under the hood, it utilizes Tailwind CSS 4 to manage styling configurations efficiently.

Getting Started

Follow these simple commands to get the development environment running. Choose your package manager below:

1. Install Dependencies
bun install
2. Run Development Server
bun dev
3. Build for Production
bun run build
1. Install Dependencies
npm install
2. Run Development Server
npm run dev
3. Build for Production
npm run build
1. Install Dependencies
yarn install
2. Run Development Server
yarn dev
3. Build for Production
yarn build

Font Customization

Habitline uses Next.js integrated Google Fonts (next/font/google) to fetch fonts dynamically and optimize layout shifts.

Step 1: Import font and declare variable in Layout

Open src/app/layout.tsx and configure your font imports:

import { Google_Sans_Flex, Stack_Sans_Headline } from "next/font/google";

const googleSansFlex = Google_Sans_Flex({
  variable: "--font-body",
  subsets: ["latin"],
  display: "swap",
});

const stackSansHeadline = Stack_Sans_Headline({
  variable: "--font-heading",
  subsets: ["latin"],
  display: "swap",
});

Step 2: Add font class to html/body tag

Still inside src/app/layout.tsx, load it into the template wrapper classes:

<body className={`bg-body-bg ${googleSansFlex.variable} ${stackSansHeadline.variable}`}>

Step 3: Define Font in CSS Theme

Tailwind CSS 4 reads your CSS variables directly. In src/assets/css/_config.css, map them:

@theme {
    --font-body: "Google Sans Flex", sans-serif;
    --font-heading: "Stack Sans Headline", sans-serif;
}

Theme & Colors Customization

Tailwind CSS v4 introduces the new CSS-first configuration via `@theme` directives instead of standard JS files. You can change Habitline's primary accent colors by updating the variables in:
src/assets/css/_config.css 

/* src/assets/css/_config.css */

@theme {
    --font-body: "Google Sans Flex", sans-serif;
    --font-heading: "Stack Sans Headline", sans-serif;

    --color-primary:#0022ff;
    --color-primary-1:#ff4c00;
    --color-primary-2:#12a70a;
    --color-primary-3:#0022ff;
    --color-primary-4:#ff00a1;
    --color-primary-5:#0059ff;
    --color-primary-6:#9000ff;
    --color-primary-7:#ff0000;
    --color-primary-8:#0283a7;

    --color-secondary-1: #acffc5;
    --color-secondary-2: #f3fe97;

    --color-body-bg: #f7f7f7;
    --color-body-color: var(--color-default-600);

    --color-default-50: var(--color-zinc-50);
    --color-default-100: var(--color-zinc-100);
    --color-default-200: var(--color-zinc-200);
    --color-default-300: var(--color-zinc-300);
    --color-default-400: var(--color-zinc-400);
    --color-default-500: var(--color-zinc-500);
    --color-default-600: var(--color-zinc-600);
    --color-default-700: var(--color-zinc-700);
    --color-default-800: var(--color-zinc-800);
    --color-default-900: var(--color-zinc-900);
    --color-default-950: var(--color-zinc-950);
}

Tip: Once updated, Tailwind CSS 4 JIT compiler will automatically compile new utility classes like `bg-primary`, `text-primary`, and `hover:bg-primary-hover` across all routes.
